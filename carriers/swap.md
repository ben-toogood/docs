### Connecting Swap 

In order to connect your Swap  account to Pimento, we require the following information:

- API User
- API Token

<sup>Note: These will both be provided by your Swap  account manager</sup>

To connect Swap you will need to head to [Shipping > Carriers](https://app.getpimento.com/clients/shipping/carriers) located on the left hand side of the navigation bar:
<img src="/images/shipping-carriers.png" alt="Swap Connect" />

Then find Swap with the carrier list
<img src="/images/swap-setup.png" alt="Swap Connect" />

Enter the details you have been provided
<img src="/images/swap-settings.png" alt="Swap Settings" />

Once done hit save and if everything is connected you will see the connected screen:
<img src="/images/swap-connected.png" alt="Swap Connected" />

### Supported Services

Pimento Supports the following Swap  services:

| Service Name |
| ------------ |
| Swap FedEx International Priority DDP |
| Swap FedEx International Connect Plus DDP |
